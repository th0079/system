3T3-Tier Login Service

WAS(Application Tier)에 연결할 수 없습니다

이 페이지는 Web Tier(Nginx)가 직접 응답한 것입니다. Nginx 는 정상이지만 뒤쪽의 Gunicorn/Flask(127.0.0.1:8000)가 응답하지 않습니다. (502/503/504)

VM 터미널에서 아래 명령으로 WAS 상태를 확인하세요.
sudo systemctl status loginapp sudo journalctl -u loginapp -n 50 --no-pager sudo systemctl restart loginapp
served by Nginx (Web Tier)
